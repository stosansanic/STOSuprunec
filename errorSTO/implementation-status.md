# Стан впровадження оптимізацій трафіку

Оновлено 11.10.2026. **Локально реалізовані 29/29 пунктів.** Production-встановлення і приймання не виконані; реальна економія Supabase Egress ще не виміряна. Повні вимоги: [bag.md](bag.md).

## Перевірки

- Повний локальний прогін: **360/360 PASS**, 0 пропусків.
- Окремий браузерний тест Нової пошти: **1/1 PASS**, локальні вигадані дані, зовнішні запити заблоковані.
- TypeScript та `npm run build:vercel`: PASS. Vite попереджає про великий frontend chunk і змішаний import; це не помилка збірки й не вимірювання Supabase Egress.
- 42 read-only міграції: синтаксис і повторне встановлення перевірені у PGlite; профільні тести охоплюють RLS, фінансові формули, понад 1000 записів, повторні та конкурентні записи.
- Схему блокувань і типів полів звірено з наданою папкою «Основа проектів» без виконання повного SQL-шаблону. Це не підтверджує фактичну схему production.

## Обґрунтовані рішення

- №15: збережено чинне підсумовування тривалості перекриттів, щоб оптимізація не змінила бізнес-результати.
- №18: заплановані SQL-перевірки виконуються сервером із lease; подієві browser new/old правила збережено, оскільки polling втратив би проміжні події. Доставки захищені атомарним claim.
- №19: явно запущені масові інструменти ТО/повернення клієнтів можуть прочитати всю дозволену історію вузькими сторінками; звичайне відкриття чату її не завантажує.
- Повна історія, архів ТТН та чернетки не видалялися заради економії. Нових баз чи таблиць для цих оптимізацій немає.

## Встановлення і завершення приймання

Дотримуватися [інструкції встановлення](../supabase/setup/traffic-optimization/README.md): пакет читання → окремі write-міграції → відповідні Edge Functions → frontend. Не запускати всі історичні міграції або повний шаблон бази.

Після встановлення перевірити фактичні RLS/cron, дві робочі сесії, права працівників, офлайн/reconnect і контрольні фінансові сценарії. Порівняти Network та Supabase Usage за однаковим навантаженням. До цього не можна стверджувати, що всі production-критерії закриті або називати відсоток економії.
