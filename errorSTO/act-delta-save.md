# Часткове збереження акта — 12.10.2026

Кнопка збереження модалки використовує guarded_read_act_delta і guarded_patch_act_with_stock. Пакет містить лише зміни JSON-шляхів, checksum, акт, власника блокування, нову ревізію та змінений аванс. Старий і новий повні JSON не відправляються в RPC запису. Для однакової довжини масивів змінюються вкладені значення; зміна довжини передає лише відповідний масив. Видалення поля відрізняється від JSON null.

Сервер блокує рядок, перевіряє lease, RLS, checksum даних/авансу/приймальника/закриття, закритий і заморожений статус. Зміни накладаються на актуальний документ. Існуюча транзакція збереження застосовує різницю складських кількостей і повертає коротку квитанцію. Незмінений документ та аванс не викликають UPDATE.

Фінансова синхронізація та оновлення глобального кешу пропускаються для змін лише текстових полів/пробігу, якщо фінансові поля не змінилися, попередня синхронізація завершена і приймальника вже задано. Зміни деталей/робіт/знижок та незавершена синхронізація зберігають попередній фінансовий процес. Локальна офлайн-чернетка залишається повним знімком для відновлення.

Обмеження: перед збереженням збережено одне повне контрольне читання акта для існуючої перевірки застарілого редактора та прихованих колонок. PostgreSQL фізично створює нову версію JSONB-рядка. Це оптимізація передачі і зайвих записів, а не фізичний запис окремих байтів. Фотоархів використовує окремий photo_url; цей шлях не переписується кнопкою збереження JSON акта.
