# Нова пошта — архів із ручним оновленням

Онлайн-режим замінено архівом у таблиці `public.novaposhta`. Список і деталі читаються з бази; запити до НП виконуються кнопкою «Оновити з Нової пошти». У `acts.novaposhta` зберігаються тільки номери ТТН; номери актів — у `novaposhta.act_ids`.

Актуальна інструкція встановлення, перенесення й опис полів: [nova-poshta-new-project.md](nova-poshta-new-project.md).

Логін, зашифровані пароль та API-ключ залишаються у `settings.novaposhta`. Ключ `NP_ENCRYPTION_KEY` при оновленні не змінювати. Старі міграції залишені як історія; для встановлення використовуйте згенерований `01-database.sql`.
